# My first project

Projet Unity avec une scène 3D inspirée de Dakar, au Sénégal.

## Lancer le projet

1. Ouvrir le dossier du projet dans Unity **6000.6.7f1**.
2. Ouvrir `Assets/Scenes/SampleScene.unity`.
3. Cliquer sur **Play**.

## Scène de Dakar

Le composant `DakarCloudyScene`, attaché à la caméra de la scène, crée
l'environnement au démarrage : une route bordée de bâtiments et de palmiers,
un ciel nuageux stylisé, un éclairage couvert et un taxi jaune à détails noirs.
Les objets et matériaux sont générés par script ; aucun modèle ou paquet
graphique externe n'est nécessaire.

La scène est une présentation visuelle : le taxi n'est pas contrôlable.
